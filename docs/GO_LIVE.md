# تشغيل الموقع أونلاين (Go live)

n8n و GoHighLevel جاهزين عند إبراهيم. المطلوب هنا رفع الموقع على استضافة فيها PHP وتفعيل الربط فقط.

## 1. الاستضافة
- PHP 8 مع cURL، و HTTPS مفعّل على الدومين (Hostinger أو أي cPanel).
- GitHub Pages لا تنفع للنسخة الحيّة لأنها لا تشغّل PHP (تبقى معاينة فقط).

## 2. جهّز الملفات
```bash
python3 scripts/export_site.py --output dist
```
ارفع **محتوى** مجلد `dist` إلى `public_html`. فيه مجلد `api/` بملفّي الربط `apply.php` و `book.php`.

## 3. عنوان n8n (خاص، ليس في المستودع)
على الاستضافة، داخل `public_html/api/`:
1. انسخ `relay-config.example.php` باسم `relay-config.php`.
2. ضع فيه العنوان الذي يعطيك إياه إبراهيم (`n8n_base`، شكله `http://…:5678/webhook`).

لا ترفع `relay-config.php` إلى GitHub (موجود في `.gitignore`). بدونه يرد الربط بـ `503 not_configured`.

## 4. عدّل `config.js` على الاستضافة
- `webhookUrl: "api/apply.php"`
- داخل `booking`: `endpoint: "api/book.php"` و `test: false`

هذه القيم تبقى فارغة في المستودع عمدًا حتى تبقى نسخة GitHub Pages معاينة لا ترسل شيئًا.

## 5. افحص الربط
افتح `https://الدومين/api/book.php?days=14`:
- `{"ok":true,…,"days":[…]}` ← الربط شغّال.
- `not_configured` ← الخطوة 3 ناقصة.
- `upstream_unreachable` ← الاستضافة تمنع الاتصال الخارجي على المنفذ 5678؛ اطلب من الدعم الفني فتحه، أو راجع إبراهيم.

## 6. جرّب كل مسار مرة
- الكورس: «سجّل الآن» → البيانات → «للدفع، تواصل معنا على واتساب».
- التدريب الخاص: اختر شهرًا → «نسّق موعدًا قادمًا» → البيانات → نفس الخطوة.
- الاستشارة: «احجز موعدك» → اختر موعدًا → الموعد + زر واتساب.
- المؤشرات: نموذج الاهتمام.

يجب ألا تظهر «وضع المعاينة» في أي صفحة. بعد التجربة أخبر إبراهيم ليتأكد من وصول الطلبات إلى GoHighLevel ويحذف التجارب.

## 7. قبل الإعلان (قرار إبراهيم)
- الصفحات فيها `noindex, nofollow`؛ احذفه فقط عند الموافقة على ظهور الموقع في جوجل.
- لا توكنات أو مفاتيح في `config.js`، ولا دفع ولا كريبتو على الموقع.
